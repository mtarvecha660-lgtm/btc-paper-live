How it works

  • Every ~15 minutes GitHub runs the bot for free. It reads public BTC prices (no exchange account, no keys).
  • Strategies decide on each closed 1-hour candle and “fill” at the next candle’s open, paying a 0.1% fee + 0.05% slippage, like a real exchange.
  • Risk rules: 1% of the account risked per trade, max 50% in one trade, a stop-loss on every trade, trading pauses for the day after a 3% loss. No leverage, no shorting.
  • “Just Hold BTC” buys once at the start and never sells. A strategy is only worth anything if it beats that over weeks.
  • Every value counts an open position as if it were sold right now (fee + slippage), the same rule for the strategies and for Just Hold BTC, so the race is fair.
  • Profit factor = money won ÷ money lost on closed trades (above 1 is good). Expectancy = average result per closed trade. Fees % of gross = how much of the before-fee profit or loss went to fees. Sortino = return per unit of downside swings (higher is better).

Past or paper results don’t predict real results. Not financial advice. Code & raw data on GitHub
